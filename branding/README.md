# Iro identity

Original Mount Fuji / sun symbol generated with the built-in image_gen tool on 2026-11-10, while the project was named Fuji-ADB. The transparent original is `iro-logo-original.png`. Runtime PNG and multiresolution ICO derivatives are in `src/iro/assets/`. The original generation prompt below is preserved verbatim. Resizing and ICO/BMP packaging preserve the generated mark; no third-party logo was traced or copied.

## Generation prompt

Use case: logo-brand. Asset: production application icon / logomark for Fuji-ADB, a quiet Fujifilm recipe library for Windows. Create one minimal Japanese-inspired geometric mark: a simple ink-black triangular Mount Fuji silhouette, a small flat vermilion sun, and a single restrained negative-space aperture or horizontal snowcap cut suggesting photography. Centered standalone symbol, bold readable silhouette at 32px, precise clean vector-like edges, balanced generous transparent margin (symbol occupies about 75 percent of square). Warm paper-and-ink design sensibility, understated Japanese modernism, flat two-color treatment. No lettering, no kanji, no wordmark, no borders, no gradients, no texture, no mockup, no shadows. Actual transparent background. Original identity, do not reproduce Fujifilm or another company's logo.

## GUI reference

The local Koban Windows and ZenPDF Windows projects share the washi/sumi palette used here: warm paper `#f5f3ee`, surface `#fbfaf7`, ink `#1f1e1c`, hairline `#e3dfd6`, vermilion `#b9432f`. Dark mode follows their sumi equivalents. Segoe UI, fine rules, generous whitespace, a collection sidebar and subdued toolbars extend that vocabulary to recipe editing. The GUI remains Python/Tkinter; no Tauri migration is required for the MSI build.
